# Project Roadmap

This document outlines the future direction of TinkerDeck Learn.

## Current Status: v1.0.0 ✅

**Completed:**
- 4 beginner lessons (Blink, Button, Sensor, Display)
- Comprehensive documentation and guides
- CI/CD validation pipeline
- Project framework for contributors

---

## v1.1.0: Intermediate Content (Q4 2024)

### Lessons
- **05 - Temperature Monitor** — Read DHT11/LM35 temperature sensors
  - Concepts: Sensor libraries, data conversion, Serial output
  - Project: Digital thermometer display

- **06 - Motion Detector** — PIR motion sensor with alerts
  - Concepts: Digital input from analog sensor, state changes
  - Project: Motion-activated light alarm

- **07 - Home Automation Basics** — Control multiple devices
  - Concepts: Relay modules, power circuits, safety
  - Project: Light and fan controller

- **08 - Data Logging** — Store sensor readings to EEPROM
  - Concepts: Arduino memory, data persistence, timestamps
  - Project: Environmental data logger

### Enhancements
- Add 3D component models (.glb files for visualization)
- Create reference pinout diagrams for Arduino
- Add component datasheet links
- Create project ideas gallery

---

## v1.2.0: Advanced Topics (Q1 2025)

### Lessons
- **09 - Wireless Basics** — WiFi connectivity with Arduino MKR
  - Concepts: WiFi module setup, network protocols
  - Project: Cloud-connected sensor

- **10 - Bluetooth Communication** — Bluetooth module integration
  - Concepts: Serial communication, mobile app integration
  - Project: Smartphone-controlled LED

- **11 - Real-time Visualization** — Streaming data to dashboard
  - Concepts: APIs, JSON, web dashboards
  - Project: Live sensor monitoring dashboard

- **12 - Custom Shields** — Designing PCBs and shields
  - Concepts: Circuit design, schematic creation
  - Reference: Shield design guidelines

### Enhancements
- Video tutorials for each lesson (30-60 seconds)
- Interactive wiring simulator
- Code playground environment
- Project kit recommendations

---

## v2.0.0: Ecosystem & Community (H2 2025)

### Features
- **Learning Paths:** Curated sequences for different goals
  - "Build a Weather Station" path
  - "Home Automation Starter" path
  - "IoT Project Builder" path

- **Project Gallery:** User-submitted projects and variations
  - "Cool projects people built with these lessons"
  - Community showcase

- **Interactive IDE Integration:** Direct Arduino IDE plugin
  - One-click lesson code loading
  - Auto-upload verification

- **Mobile App:** Offline lesson access
  - iOS/Android app with lessons
  - Wiring diagram viewer
  - Progress tracking

### Community
- Discussion forum
- GitHub Discussions enabled
- Discord server for real-time help
- Monthly project challenges
