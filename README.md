# TinkerDeck Learn

An open-source Arduino learning platform with hands-on lessons for beginners. Start with the fundamentals and progress to building real interactive projects.

## 🎯 What is This?

TinkerDeck Learn provides step-by-step Arduino lessons designed for:
- **Complete beginners** - no electronics experience needed
- **Hands-on learners** - learn by building real projects
- **Self-paced** - work through lessons at your own speed

Each lesson includes:
- 📖 Clear explanation and concepts
- 💻 Ready-to-use Arduino code
- 🔌 Detailed wiring diagrams
- 📋 Complete parts list
- 🔧 Troubleshooting guide
- 🎮 Challenge projects

## 🚀 Quick Start

1. **Choose a lesson** from the `lessons/` directory
2. **Gather materials** from the parts list
3. **Follow the wiring diagram** to build your circuit
4. **Upload the code** to your Arduino
5. **Troubleshoot** using the guide if needed

## 📚 Lessons

### Beginner
- **[01 - Blink](lessons/01-blink/)** - Make an LED blink (15 min)
  - Concepts: Digital output, pinMode(), digitalWrite(), delay()
  
- **[02 - Button Input](lessons/02-button-input/)** - Read a button press (20 min)
  - Concepts: Digital input, conditional logic, debouncing
  
- **[03 - Sensor Reading](lessons/03-sensor/)** - Read analog values (25 min)
  - Concepts: Analog input, PWM, sensor calibration
  
- **[04 - Mini Display](lessons/04-mini-display/)** - Show text on LCD (30 min)
  - Concepts: I2C communication, display control, string formatting

## 🛠️ What You'll Need

### Hardware
- Arduino Uno microcontroller
- USB cable (Type A to Type B)
- Breadboard (solderless)
- Jumper wires
- LEDs, resistors, buttons, sensors (specific parts listed per lesson)

### Software
- Arduino IDE (free download: https://www.arduino.cc/en/software)
- USB drivers for Arduino (usually automatic)

## 📖 How to Use This Repository

## ❓ FAQ

**Q: Do I need experience with electronics?**
A: No! These lessons assume zero prior knowledge.

**Q: Which Arduino board should I use?**
A: Start with Arduino Uno. Most lessons work with other boards too.

**Q: Can I use different components?**
A: Yes, but check specifications. Pin numbers and some code may change.

**Q: How long does each lesson take?**
A: 15-45 minutes depending on difficulty and your pace.

**Q: Where can I get the parts?**
A: Arduino starter kits are available on Amazon, SparkFun, Adafruit, etc.

**Q: What if my project doesn't work?**
A: Check the troubleshooting.md in your lesson directory first!
