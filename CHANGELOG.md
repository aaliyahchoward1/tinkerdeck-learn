# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2024-08-21

### Added
- **Lesson 01 - Blink**: Introduction to digital output with LEDs
  - Complete tutorial with theory and code breakdown
  - Ready-to-upload Arduino sketch (blink.ino)
  - Detailed wiring diagram and breadboard layout
  - Bill of materials with costs
  - Comprehensive troubleshooting guide (10+ solutions)

- **Lesson 02 - Button Input**: Digital input and conditional logic
  - Button reading with debouncing
  - Pull-down resistor explanation
  - Complete button control example
  - Troubleshooting for common input issues

- **Lesson 03 - Sensor Reading**: Analog input and PWM output
  - Analog-to-digital conversion (analogRead)
  - PWM brightness control (analogWrite)
  - Two sensor options: potentiometer and photoresistor
  - Sensor calibration and noise filtering techniques
  - Three working code examples

- **Lesson 04 - Mini Display**: I2C communication and LCD control
  - I2C protocol explanation
  - LCD display initialization and control
  - I2C address scanner tool
  - Real-time sensor data display
  - Multiple code examples for different use cases

- **Project Framework**
  - LESSON_TEMPLATE.md: Comprehensive guide for creating new lessons
  - CONTRIBUTING.md: Guidelines for contributors
  - Consistent lesson structure across all content
  - GitHub Actions CI/CD pipeline for validation

- **Documentation**
  - Comprehensive README with setup instructions
  - Project structure overview
  - Skills progression checklist
  - Learning path diagram
  - Detailed FAQ (15+ questions)
  - Prerequisites and installation guide

- **Automation**
  - Python lesson validation script (check-lessons.py)
  - GitHub Actions workflow for automated testing
  - JSON validation for parts lists
